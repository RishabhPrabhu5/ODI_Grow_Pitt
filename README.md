# Common Ground — Grow Pittsburgh project board (mockup)

A clickable website mockup that replaces Grow Pittsburgh's cross-team Excel tracker with one shared board for its four departments: Operations, School Gardens, Community Projects and Farm Education.

Open `index.html` in any browser. No build step or server is needed.

## What it shows

- **Beds** – each department's projects as cards, with lead, growth stage, partners, and which other teams are involved. Switch to "Arrange beds by: Growth stage" to see the pipeline across all teams.
- **Season** – a 2026 timeline of every project against Pittsburgh's average last and first frost dates.
- **Roots** – a map of which departments work with which partner organizations, highlighting partners shared by more than one team.
- **Partner view** toggle – hides staff notes and internal-only projects so the screen can be shown to volunteers and partners.
- **Plant a project** – a form to add a project (saved in the browser for the demo).

Growth stages: Seed = planning, Sprout = getting started, Bloom = in full swing, Harvest = wrapped up.

All projects, people and dates are sample data.
